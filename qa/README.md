# Evidence and limitations

The release contains synthetic evaluation records only. Saved responses are historical
outputs of a real locally installed Ollama model, not a response generated when a reader
opens the file. Raw response bytes are preserved from the development artifacts.

## Automated checks

[automated-tests.json](automated-tests.json) records the latest 27-test development run,
the test command, date and source-log checksum. It deliberately excludes the original
machine-specific log. Test sources are included at repository root. These checks use
mocked AI calls for repeatability; the model runs below are separate.

## Real local review records

[manual-audit.json](../evaluation-v2/manual-audit.json) documents every claim in nine
second-batch responses: 24 claims total. The implementing AI assistant authored the
synthetic fixtures and performed the manual comparison. This was not independent or
held-out evaluation. Earlier incorrect/ambiguous attempts remain available alongside
selected responses.

These ten selected observations passed reference validation and were manually compared
with the synthetic source. The final prompt refinement was checked only by the focused
context-limits rerun. The other three use the immediately preceding prompt; both
instructions are archived. This selection is not an accuracy rate.

[semantic-audit.md](../semantic-audit.md) explains the earlier failed citation attempts,
incorrect EOF conclusion, lost file context, and ambiguous retained-subexpression claim.
The first-stage `local-live-review-validated.json` filename is historical: its validation
failed. Historical provenance may use `fixture_used: false`; this means no saved answer
was substituted, not that the input was real-world. All included inputs are synthetic.

The initial [importable example](../ai-review.example.json) was AI-authored in a Codex
conversation, not generated by the application. Its [provenance](../ai-review-provenance.md)
is separate from real localhost model records.

Reference validation does not establish semantic truth. Metadata-only and binary
changes are outside the AI changed-text projection. The app does not execute tests or
code, certify security, inspect an entire repository, or prove runtime behavior.
